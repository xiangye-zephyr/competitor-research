# 竞品研究室

把账号研究串成可操作的流程：了解受众、浏览选题、拆解作品，再把分析转化为自己的创作方案。

## 使用

下载 `index.html`，用浏览器打开即可。页面为独立 HTML，无需安装依赖。

- 账号总览与受众定位。
- 316 条作品样本，可搜索、筛选和比较。
- 8 个精读案例，展示结构、表达与复用思路。
- 选择写作套路，填写自己的素材，复制 AI 指令。

网页只生成提示词，不调用 AI；原作品链接需要联网访问。样本数据为历史快照，分析属于研究判断，不代表账号当前状态或运营方观点。

## 公开范围

已移除私人飞书、笔记入口和笔记文章标识；内部记录编号已替换为本仓库的示例编号。保留公开抖音原作品链接、来源口径和页面交互。

以「赫子讲职业规划」作为研究案例。第三方账号内容与图片的相关权利归原权利人，本项目不代表与其合作或获得背书。
