# 竞品研究室

**看懂内容，拆出方法。**

一个面向内容创作者的交互式账号研究工具。以「赫子讲职业规划」为案例，将受众画像、选题分布、作品数据和文案拆解放在同一张研究桌上，从观察一个账号，到形成自己的创作思路。

## 为什么做这个

收藏了很多爆款，写稿时却依然不知道从哪里下手。单独看点赞数，解释不了作品为什么有效；把文案照搬过来，也很难适配自己的受众。

竞品研究室把研究过程串起来：先看账号在回应谁的问题，再比较不同题材的表现，回到具体作品拆解开头、结构与表达，最后用自己的素材尝试新的写法。

## 五个研究入口

| 模块 | 可以探索什么 |
| --- | --- |
| 账号总览 | 内容重心、代表作品与值得进一步验证的判断 |
| 受众与定位 | 受众画像、需求场景与账号的表达关系 |
| 选题地图 | 搜索、筛选 316 条作品，按互动指标或发布时间排序 |
| 作品拆解 | 阅读 8 篇精读案例，对照作品的结构与互动表现 |
| 创作方案 | 从 4 套写作结构出发，填入自己的素材，生成可复制的 AI 写稿提示词 |

## 打开项目

在仓库顶部选择 **Code → Download ZIP**，解压后用浏览器打开 `index.html` 即可。无需安装依赖或配置账号。

建议从「账号总览」开始，选一个感兴趣的题材进入「作品拆解」，再到「创作方案」试写。提示词在页面内生成，复制到所使用的 AI 工具后继续创作；访问原作品需要联网。

## 关于这个案例

作品样本覆盖 2024 年 10 月至 2026 年 9 月，资料整理于 2026 年 9 月 17 日。互动数据为历史快照；拆解与创作建议属于独立研究，不代表账号运营方观点，也不构成效果承诺。

原作品链接可在页面中查看。第三方作品与图片的权利归原权利人。
